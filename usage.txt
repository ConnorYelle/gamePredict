============================================================
 MLB GAME PREDICTION ENGINE — COMMANDS
============================================================

UNIFIED CLI
------------------------------------------------------------

gamePredict <command> [options]
    One entry point for the whole project. Use the gamePredict / gamePredict.cmd
    / gamePredict.ps1 wrapper (put the repo folder on your PATH) or run it as
    `python gamePredict.py <command>`. Run `gamePredict help` for the full list.

    Key commands: run, live, test, train, backtest, validate, fetch, stats,
    pitchers, archive, metrics, plot. Each forwards its options to the
    underlying script, so e.g. `gamePredict train --iters 60` works.

gamePredict live [--port N] [--host H] [--no-browser] [--predictions PATH]
    Starts a local web server (default http://127.0.0.1:8000) and opens a
    dashboard that refreshes every 30s: live scores and inning, the starting
    pitchers and the pitcher on the mound, and a green/red border once a game
    is final (green = the model's pick won, red = it lost) with the final score.
    Reads outputs/predictions.txt, so run `gamePredict run` first.

gamePredict test [--coverage]
    Runs the full test suite. With --coverage, measures coverage via coverage.py
    (pip install -r requirements-dev.txt) and writes an HTML report to htmlcov/.


MAIN
------------------------------------------------------------

python runPipeline.py   (or: gamePredict run)
    Does everything: gets today's stats and games, makes predictions, and
    saves yesterday's final scores. This is the main command.

python scripts/train_weights.py
    Teaches the model from past seasons so future predictions are smarter.
    Automatically records the held-out validation accuracy/Brier/log-loss to
    data/metrics_history.jsonl. Add -n "what changed" to label the run, or
    --no-log to skip recording.

python scripts/validate_predictions.py --backtest
    Replays a past season and reports how accurate the model was.

python scripts/track_metrics.py -n "what I changed"
    Backtests the current model, records accuracy/Brier/log-loss (with the note
    and git commit) to data/metrics_history.jsonl, then prints the whole history
    so you can see if a change helped. Use --show to just view the history.
    Commit data/metrics_history.jsonl to keep the record across changes.

python scripts/plot_metrics_history.py
    Renders the recorded history to docs/metrics_history.svg and embeds it (plus
    the latest numbers) in the "Metrics history" section of README.md. Run it
    after recording new runs to refresh the chart.

python scripts/archive_schedule.py
    Saves yesterday's games and final scores into data/schedules/.


TRAIN OPTIONS (add to train_weights.py)
------------------------------------------------------------

--train-seasons 2022,2023,2024   Learn from these seasons (comma-separated).
--val-season 2025                Season used to test itself.
--iters 40                       How hard it tries (higher = slower).
--no-pitchers                    Use team stats only, ignore pitchers.
--dry-run                        Show results but don't save them.


BACKTEST OPTIONS (add to validate_predictions.py --backtest)
------------------------------------------------------------

--season 2023          Which season to replay.
--start 2025-05-01     Only games on/after this date.
--end 2025-10-31       Only games on/before this date.
--no-pitchers          Use team stats only, ignore pitchers.


CHECK A SAVED DAY
------------------------------------------------------------

python scripts/validate_predictions.py --predictions data/schedules/05-29-26/predictions.txt --results data/schedules/05-29-26/final_scores.csv
    Compares one saved day's predictions to the real final scores.
    (Replace 05-29-26 with a real folder name.)


SAVE PAST DAYS (add to archive_schedule.py)
------------------------------------------------------------

--date 2026-05-29                       Save one specific day.
--start 2026-05-01 --end 2026-05-29     Save a range of days.

Get-ChildItem data/schedules
    Lists the days you've already saved.


INDIVIDUAL STEPS (normally run automatically)
------------------------------------------------------------

python scripts/statsCollector.py
    Downloads today's team batting/fielding stats from the MLB Stats API into
    data/rawData/<date>/. Idempotent: if today's files already exist it skips
    the API call. Add --force to refetch anyway.

python scripts/scheduleFetcher.py
    Gets today's games and starting pitchers into outputs/games.txt.

python scripts/collect_pitchers.py
    Gets today's starting pitchers' stats into StartingPitchers.csv.


MAINTENANCE (run rarely)
------------------------------------------------------------

python scripts/update_readme_metrics.py
    Updates the accuracy summary in README.md.

python scripts/install_git_hook.py
    One-time setup so README accuracy updates automatically with Git.

python -m unittest discover
    Runs the automated tests (run from the repo root). The C++ engine tests
    need the g++ compiler; they verify compilation and, where the local
    toolchain can link, also build and run the engine.
